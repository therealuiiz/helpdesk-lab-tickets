# Helpdesk Lab Tickets

Este repositório contém uma simulação prática de ambiente de Helpdesk Jr, com foco em troubleshooting de sistemas Windows, redes e aplicações corporativas.

O objetivo é desenvolver habilidades de suporte técnico através da criação e documentação de tickets simulados, seguindo uma estrutura próxima de ambientes reais de TI.

# Conteúdo do repositório

- Tickets de suporte técnico simulados (incidentes comuns de Helpdesk)
- Documentação de resolução de problemas (troubleshooting)
- Base de conhecimento (knowledge base) com soluções e conceitos técnicos
- Simulação de ambiente de suporte e diagnóstico de problemas

# Estrutura dos tickets

Cada ticket contém:
- Descrição do problema
- Ambiente afetado
- Diagnóstico realizado
- Solução aplicada
- Resultado final
- Aprendizados técnicos

# Tecnologias e conceitos abordados

- Windows (básico de troubleshooting)
- Redes (DNS, conectividade, IP)
- Aplicações corporativas (ex: Outlook)
- Diagnóstico e resolução de incidentes

# Objetivo

Simular atividades reais de Helpdesk Jr para desenvolvimento de habilidades práticas em suporte técnico e preparação para atuação em ambientes corporativos de TI.**
